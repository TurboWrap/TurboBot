# TurboBot
TurboBot is a discord bot to moderate and fix TurboWrap comments.

# Getting Started
- If you want to get Discord 🤖 on your desktop, go to [Download](https://discord.gg/download).
- we are a nonprofit scratch mod to add more features and advanced implementation.

# Upstream GUI
if you just want to play with the upstream TurboWrap GUI, go to: [Turbowrap-gui](https://github.com/TurboWrap/turbogui). It already contains powerful tools and plugins right out of the box. Plus an extra packager for .wrap projects.
